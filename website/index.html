Subscribe (GitHub only)

This project uses only GitHub. No external form services or third-party databases.

Email subscriptions are stored in a simple JSON file inside this repository: data/subscribers.json

To subscribe:

  • Open a new GitHub Issue with the title Subscribe and include your email in the body.
  • Or star / watch this repository to receive GitHub notifications when new issues are published.

Your email will be added to data/subscribers.json by the maintainer. You can unsubscribe anytime by opening another issue or replying to a newsletter.
